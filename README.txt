ESTUDIARBRI WEBSITE
===================

Files:
- index.html                  Home page
- math/fractions.html         Math Fractions quiz

IMPORTANT:
For iPad/iPhone, publish this folder as a website and open the HTTPS link in Safari.
Do not send fractions.html itself through WhatsApp as a file. Send the published website URL.

GitHub Pages quick setup:
1. Create a new GitHub repository (for example: EstudiarBRI).
2. Upload the CONTENTS of this folder, keeping the math folder.
3. In the repository open Settings > Pages.
4. Under Build and deployment choose Deploy from a branch.
5. Select branch main and folder /(root), then Save.
6. GitHub will show the public HTTPS address.
7. Send that HTTPS address through WhatsApp.

Future quizzes can be added under the appropriate subject folder without changing the main website address.
